# S7 — L1 Batcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the L1 batcher subsystem that posts sealed L2 blocks to Ethereum L1 via 4844 blobs, plus an L1 settlement contract that records batches and a library that reconstructs the L2 stream from L1 calldata + blobs.

**Architecture:** New `crates/kardamom-batcher` consumes `BlockBoundary` markers from channel C and the corresponding raw `TxEnvelope` range from the channel-B archive, zstd-compresses the concatenated RLP-framed stream, splits it into 4844-blob-sized chunks with a tiny header that lets a reader reassemble across batches, computes KZG commitments via the `c-kzg` crate (re-exported through `alloy-consensus`/`alloy-eips`), and submits one EIP-4844 transaction per posting cycle to a new `KardamomL2Settlement.sol` contract. The contract sits behind the same ERC-7955 / KardamomFactoryV1 UUPS proxy pattern as `ETHLockbox`, so deployment goes through the existing `crates/deployer` with one new `ContractId` variant. A separate library function in the batcher crate is the inverse: given an L1 tx hash + the corresponding blobs (fetched via a beacon-node sidecar API or supplied directly in tests), it reassembles the L2 tx stream and the receipt range, used by the §6 L1 round-trip conformance test. Singleton + hot standby uses the same `kardamom-leases` primitive as S5 (defined here as a shared dep; if S5 hasn't shipped yet, this plan creates `crates/kardamom-leases` and S5 consumes it).

**Tech Stack:** Rust (alloy 2.0 — `alloy-consensus`, `alloy-eips`, `alloy-provider`, `alloy-sol-types`, `alloy-network`, `alloy-rlp`), `c-kzg` 2.x (via alloy re-export), `zstd` 0.13 (pure-Rust binding to system libzstd), Solidity 0.8.26 + Foundry + OpenZeppelin Upgradeable, anvil (via `alloy-node-bindings`) for integration tests.

**Branch:** `claude/s7-l1-batcher` (already created off `claude/s6-state-writer`; final PR opens against `main` once preceding subsystem PRs land).

**Reference specs:** `docs/specs/2026-05-23-high-throughput-sequencer-design.md` §2.8 (this subsystem), §6 (L1 round-trip conformance test), `docs/superpowers/plans/2026-05-19-contract-factory-and-deployer.md` (deployer + factory patterns to mirror).

**Assumed interfaces (must agree with S3 / S5):**
- `kardamom_log::BPosition { term_id: u64, term_offset: u32 }` — opaque cursor; orderable.
- `kardamom_log::TxEnvelope` — the `alloy_consensus::TxEnvelope` re-export consumed across all subsystems.
- `kardamom_log::BlockBoundary { block_number: u64, end_tx_idx: u64, l2_timestamp: u64, state_root_commitment: B256 }` — published on C by executors.
- `kardamom_log::archive::ChannelBArchive::replay_range(start: BPosition, end_inclusive: BPosition) -> impl Stream<Item = (BPosition, TxEnvelope)>` — the archive replay API the batcher pulls history from. **This API is the hard dependency on S3; it is not currently defined.** Task 1 below pins the trait signature this plan uses; if S3 ships a different signature, update Task 1 and search-and-replace `replay_range` in tasks 4, 12, 19, 24, 27.
- `kardamom_log::channel_c::subscribe_block_boundaries() -> impl Stream<Item = BlockBoundary>` — C subscription filtered to boundary markers only.
- `kardamom_leases::Lease` — see Task 2.

**V0 scope:** all features listed in the spec for S7. No fraud proofs, no validity proofs. Single L1 chain target (Ethereum mainnet / Sepolia for testing; anvil for local).

```rust
//! `BatchSource`: the channel-B + channel-C interface the batcher consumes.
//!
//! Decouples the batcher from the concrete `kardamom-log` API so this crate
//! compiles before S3 ships. The real adapter (`KardamomLogSource`) wraps S3
//! once it's available; see the binary entry point.

use alloy_consensus::TxEnvelope;
use alloy_primitives::B256;
use std::pin::Pin;

/// Canonical position on channel B. Mirrors `kardamom_log::BPosition` once that
/// type exists; until then it lives here.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct BPosition {
    pub term_id: u64,
    pub term_offset: u32,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct BlockBoundary {
    pub block_number: u64,
    /// Channel-B tx index *inclusive* of the last tx in this block.
    pub end_tx_idx: u64,
    pub l2_timestamp: u64,
    pub state_root_commitment: B256,
    /// Channel-B position of the last tx in this block (inclusive). The batcher
    /// pulls `replay_range(prev_boundary.end_position + 1, this.end_position)`.
    pub end_position: BPosition,
}

#[async_trait::async_trait]
pub trait BatchSource: Send + Sync {
    /// Subscribe to BlockBoundary events on channel C. Stream is unbounded;
    /// implementations must back-pressure on dropped consumers.
    async fn subscribe_boundaries(
        &self,
    ) -> Pin<Box<dyn futures::Stream<Item = BlockBoundary> + Send>>;

    /// Replay a range of `TxEnvelope`s from the channel-B archive. Inclusive on both
    /// ends. Must yield in canonical order.
    async fn replay_range(
        &self,
        start: BPosition,
        end_inclusive: BPosition,
    ) -> Result<Vec<TxEnvelope>, SourceError>;
}

#[derive(Debug, thiserror::Error)]
pub enum SourceError {
    #[error("archive lookup failed: {0}")]
    Archive(String),
    #[error("subscription dropped")]
    SubscriptionDropped,
}
```

```rust
//! Lease primitive: a deterministic "who is the leader right now" answer based
//! on the lowest host id among peers that have caught up past a configured
//! watermark.
//!
//! This is **not** a strong leader-election. It is CFT-only: if the current
//! leader's heartbeat lapses, the standby with the next-lowest host id picks
//! up the lease at the next tick. Used by S5 (block sealer) and S7 (L1
//! batcher). The watermark is supplied by the caller (e.g. the recorder's
//! fsync-quorum position).

use std::collections::BTreeSet;
use std::time::{Duration, Instant};

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, serde::Serialize, serde::Deserialize)]
pub struct HostId(pub u32);

#[derive(Debug, Clone)]
pub struct LeaseConfig {
    /// This host's id.
    pub self_id: HostId,
    /// How long a peer's heartbeat is considered live.
    pub heartbeat_timeout: Duration,
    /// Minimum watermark this host must reach before it can claim the lease.
    /// `Some(position)` — the caller is responsible for advancing it. `None` — no gate.
    pub min_caught_up_position: Option<u64>,
}

#[derive(Debug, Clone)]
pub struct PeerHeartbeat {
    pub host: HostId,
    pub caught_up_position: u64,
    pub last_seen: Instant,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum LeaseState {
    /// We hold the lease.
    Held,
    /// Some other host holds it.
    StandbyFor(HostId),
    /// No quorum / not yet caught up.
    Inactive,
}

/// Stateless function: given the current set of live peers + this host's caught-up
/// position, compute who should hold the lease right now. Tie-break is by lowest
/// `HostId`.
pub fn compute_lease(
    cfg: &LeaseConfig,
    now: Instant,
    self_caught_up_position: u64,
    peers: &[PeerHeartbeat],
) -> LeaseState {
    if let Some(min) = cfg.min_caught_up_position {
        if self_caught_up_position < min {
            return LeaseState::Inactive;
        }
    }

    // Live = heartbeat within timeout AND caught up past our gate.
    let mut live: BTreeSet<HostId> = BTreeSet::new();
    live.insert(cfg.self_id);
    for p in peers {
        if now.duration_since(p.last_seen) > cfg.heartbeat_timeout {
            continue;
        }
        if let Some(min) = cfg.min_caught_up_position {
            if p.caught_up_position < min {
                continue;
            }
        }
        live.insert(p.host);
    }

    let leader = *live.iter().next().expect("self always live");
    if leader == cfg.self_id {
        LeaseState::Held
    } else {
        LeaseState::StandbyFor(leader)
    }
}
```

```rust
use kardamom_leases::{HostId, LeaseConfig, LeaseState, PeerHeartbeat, compute_lease};
use std::time::{Duration, Instant};

fn cfg(self_id: u32, gate: Option<u64>) -> LeaseConfig {
    LeaseConfig {
        self_id: HostId(self_id),
        heartbeat_timeout: Duration::from_secs(1),
        min_caught_up_position: gate,
    }
}

#[test]
fn lowest_id_holds_lease() {
    let now = Instant::now();
    let peers = vec![
        PeerHeartbeat { host: HostId(2), caught_up_position: 100, last_seen: now },
        PeerHeartbeat { host: HostId(3), caught_up_position: 100, last_seen: now },
    ];
    assert_eq!(compute_lease(&cfg(1, None), now, 100, &peers), LeaseState::Held);
    assert_eq!(compute_lease(&cfg(2, None), now, 100, &peers), LeaseState::StandbyFor(HostId(1)));
}

#[test]
fn stale_peer_loses_eligibility() {
    let now = Instant::now();
    let stale = now - Duration::from_secs(5);
    let peers = vec![
        PeerHeartbeat { host: HostId(1), caught_up_position: 100, last_seen: stale },
    ];
    // Host 2 takes over because host 1's heartbeat lapsed.
    assert_eq!(compute_lease(&cfg(2, None), now, 100, &peers), LeaseState::Held);
}

#[test]
fn not_caught_up_means_inactive() {
    let now = Instant::now();
    let peers = vec![];
    let result = compute_lease(&cfg(1, Some(1000)), now, 500, &peers);
    assert_eq!(result, LeaseState::Inactive);
}
```

## Task 4: Define the frame format (TDD)

The frame format is the wire format inside the compressed blob payload. **Pinned for v0:**

```
LayerFrame (uncompressed):
  magic              : 4 bytes  = b"KAR1"
  version            : 1 byte   = 0x01
  l2_chain_id        : 8 bytes  big-endian
  num_blocks         : 4 bytes  big-endian
  blocks             : num_blocks × BlockFrame

BlockFrame:
  block_number       : 8 bytes  big-endian
  l2_timestamp       : 8 bytes  big-endian
  state_root         : 32 bytes
  end_tx_idx         : 8 bytes  big-endian
  num_txs            : 4 bytes  big-endian
  txs                : num_txs × LengthPrefixedTx

LengthPrefixedTx:
  len                : 4 bytes  big-endian
  rlp                : `len` bytes — the EIP-2718-encoded TxEnvelope
```

Then `compressed = zstd(LayerFrame)`. Then `compressed` is split into 4844 blobs per Task 5.

```rust
//! Wire format for an L2 batch *before* compression. See plan §Task 4 for the
//! pinned byte-layout. Magic `KAR1`; version 0x01.

use alloy_consensus::TxEnvelope;
use alloy_eips::eip2718::{Decodable2718, Encodable2718};
use alloy_primitives::B256;

const MAGIC: &[u8; 4] = b"KAR1";
const VERSION: u8 = 0x01;

#[derive(Debug, Clone)]
pub struct FramedBlock {
    pub block_number: u64,
    pub l2_timestamp: u64,
    pub state_root: B256,
    pub end_tx_idx: u64,
    pub txs: Vec<TxEnvelope>,
}

#[derive(Debug)]
pub struct DecodedFrame {
    pub l2_chain_id: u64,
    pub blocks: Vec<FramedBlock>,
}

#[derive(Debug, thiserror::Error)]
pub enum FrameError {
    #[error("bad magic — expected KAR1")]
    BadMagic,
    #[error("unknown version 0x{0:02x}")]
    UnknownVersion(u8),
    #[error("truncated frame at offset {0}")]
    Truncated(usize),
    #[error("tx 2718 decode failed: {0}")]
    TxDecode(String),
}

pub fn encode_frame(l2_chain_id: u64, blocks: &[FramedBlock]) -> Result<Vec<u8>, FrameError> {
    let mut out = Vec::with_capacity(1024 + blocks.iter().map(|b| 256 * b.txs.len()).sum::<usize>());
    out.extend_from_slice(MAGIC);
    out.push(VERSION);
    out.extend_from_slice(&l2_chain_id.to_be_bytes());
    out.extend_from_slice(&(blocks.len() as u32).to_be_bytes());
    for b in blocks {
        out.extend_from_slice(&b.block_number.to_be_bytes());
        out.extend_from_slice(&b.l2_timestamp.to_be_bytes());
        out.extend_from_slice(b.state_root.as_slice());
        out.extend_from_slice(&b.end_tx_idx.to_be_bytes());
        out.extend_from_slice(&(b.txs.len() as u32).to_be_bytes());
        for tx in &b.txs {
            let mut buf = Vec::new();
            tx.encode_2718(&mut buf);
            out.extend_from_slice(&(buf.len() as u32).to_be_bytes());
            out.extend_from_slice(&buf);
        }
    }
    Ok(out)
}

pub fn decode_frame(bytes: &[u8]) -> Result<DecodedFrame, FrameError> {
    let mut p = 0;
    if bytes.len() < 4 + 1 + 8 + 4 {
        return Err(FrameError::Truncated(p));
    }
    if &bytes[0..4] != MAGIC {
        return Err(FrameError::BadMagic);
    }
    p = 4;
    let version = bytes[p];
    p += 1;
    if version != VERSION {
        return Err(FrameError::UnknownVersion(version));
    }
    let l2_chain_id = u64::from_be_bytes(read_n::<8>(bytes, &mut p)?);
    let num_blocks = u32::from_be_bytes(read_n::<4>(bytes, &mut p)?) as usize;

    let mut blocks = Vec::with_capacity(num_blocks);
    for _ in 0..num_blocks {
        let block_number = u64::from_be_bytes(read_n::<8>(bytes, &mut p)?);
        let l2_timestamp = u64::from_be_bytes(read_n::<8>(bytes, &mut p)?);
        let state_root = B256::from(read_n::<32>(bytes, &mut p)?);
        let end_tx_idx = u64::from_be_bytes(read_n::<8>(bytes, &mut p)?);
        let num_txs = u32::from_be_bytes(read_n::<4>(bytes, &mut p)?) as usize;
        let mut txs = Vec::with_capacity(num_txs);
        for _ in 0..num_txs {
            let len = u32::from_be_bytes(read_n::<4>(bytes, &mut p)?) as usize;
            if p + len > bytes.len() {
                return Err(FrameError::Truncated(p));
            }
            let mut slice = &bytes[p..p + len];
            let tx = TxEnvelope::decode_2718(&mut slice).map_err(|e| FrameError::TxDecode(e.to_string()))?;
            txs.push(tx);
            p += len;
        }
        blocks.push(FramedBlock { block_number, l2_timestamp, state_root, end_tx_idx, txs });
    }
    Ok(DecodedFrame { l2_chain_id, blocks })
}

fn read_n<const N: usize>(bytes: &[u8], p: &mut usize) -> Result<[u8; N], FrameError> {
    if *p + N > bytes.len() {
        return Err(FrameError::Truncated(*p));
    }
    let mut out = [0u8; N];
    out.copy_from_slice(&bytes[*p..*p + N]);
    *p += N;
    Ok(out)
}
```

## Task 5: Blob packing — split compressed bytes across 4844 blobs (TDD)

**Files:**
- Modify: `crates/kardamom-batcher/src/blobs.rs`

A 4844 blob is exactly `4096 × 32 = 131072` bytes of field elements, but each 32-byte chunk must be a valid BLS12-381 field element — i.e. less than the field modulus. The safe canonical packing is **31 bytes of payload per 32-byte field element**, which gives **126_976 bytes per blob** of usable payload.

```rust
//! 4844 blob packing.
//!
//! Each blob is 131072 bytes = 4096 field elements × 32 bytes. To stay inside
//! the BLS12-381 field modulus regardless of payload, we pack **31 bytes per
//! field element** with the high byte set to zero. This is the standard
//! convention used by op-stack / arbitrum / scroll batchers.
//!
//! Payload per blob = 4096 × 31 = 126976 bytes.

use alloy_eips::eip4844::{Blob, BYTES_PER_BLOB, FIELD_ELEMENTS_PER_BLOB};
use alloy_primitives::B256;

/// Usable payload bytes per blob.
pub const PAYLOAD_PER_BLOB: usize = (FIELD_ELEMENTS_PER_BLOB as usize) * 31;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PackedBlob(pub Box<Blob>);

/// Split a byte stream into one or more 4844 blobs. Last blob is zero-padded.
pub fn pack_payload(payload: &[u8]) -> Vec<PackedBlob> {
    let num_blobs = (payload.len() + PAYLOAD_PER_BLOB - 1) / PAYLOAD_PER_BLOB;
    let num_blobs = num_blobs.max(1);
    let mut out = Vec::with_capacity(num_blobs);
    for i in 0..num_blobs {
        let start = i * PAYLOAD_PER_BLOB;
        let end = (start + PAYLOAD_PER_BLOB).min(payload.len());
        let chunk = &payload[start..end];
        out.push(encode_blob(chunk));
    }
    out
}

fn encode_blob(chunk: &[u8]) -> PackedBlob {
    assert!(chunk.len() <= PAYLOAD_PER_BLOB);
    let mut blob = Box::new(Blob::from([0u8; BYTES_PER_BLOB]));
    for (i, fe_payload) in chunk.chunks(31).enumerate() {
        let dst = &mut blob.0[i * 32..i * 32 + 32];
        // dst[0] = 0  (already zero)
        dst[1..1 + fe_payload.len()].copy_from_slice(fe_payload);
    }
    PackedBlob(blob)
}

/// Inverse of `pack_payload`. Strips the high zero byte of each field element
/// and concatenates. **Output length is always `n * PAYLOAD_PER_BLOB`.** Callers
/// must use the frame's length headers (KAR1) to slice off trailing padding;
/// we do not — and cannot — recover the original payload length from blob
/// contents alone.
pub fn unpack_blobs(blobs: &[PackedBlob]) -> Vec<u8> {
    let mut out = Vec::with_capacity(blobs.len() * PAYLOAD_PER_BLOB);
    for blob in blobs {
        for i in 0..(FIELD_ELEMENTS_PER_BLOB as usize) {
            let fe = &blob.0.0[i * 32..i * 32 + 32];
            out.extend_from_slice(&fe[1..32]);
        }
    }
    out
}

/// EIP-4844 versioned hash for a blob (sha256 of the KZG commitment, with the
/// first byte set to 0x01).
pub fn blob_versioned_hash(blob: &PackedBlob) -> Result<B256, KzgError> {
    let commitment = kzg_commitment(blob)?;
    Ok(alloy_eips::eip4844::kzg_to_versioned_hash(commitment.as_slice()))
}

#[derive(Debug, thiserror::Error)]
pub enum KzgError {
    #[error("c-kzg error: {0}")]
    Kzg(String),
}

pub fn kzg_commitment(blob: &PackedBlob) -> Result<c_kzg::Bytes48, KzgError> {
    use c_kzg::{Blob as CKzgBlob, KzgSettings};
    // Trusted setup ships with c-kzg as the official 4844 ceremony output.
    // The constant `ethereum_kzg_settings` is the canonical mainnet setup.
    let settings = KzgSettings::load_trusted_setup_file_from_bytes(
        c_kzg::ethereum_kzg_settings::G1_POINTS,
        c_kzg::ethereum_kzg_settings::G2_POINTS,
    )
    .map_err(|e| KzgError::Kzg(format!("trusted setup: {e:?}")))?;
    let ckzg_blob = CKzgBlob::from_bytes(&blob.0.0)
        .map_err(|e| KzgError::Kzg(format!("blob bytes: {e:?}")))?;
    let c = settings
        .blob_to_kzg_commitment(&ckzg_blob)
        .map_err(|e| KzgError::Kzg(format!("commit: {e:?}")))?;
    Ok(c.to_bytes())
}

pub fn kzg_proof(blob: &PackedBlob, commitment: &c_kzg::Bytes48) -> Result<c_kzg::Bytes48, KzgError> {
    use c_kzg::{Blob as CKzgBlob, KzgSettings};
    let settings = KzgSettings::load_trusted_setup_file_from_bytes(
        c_kzg::ethereum_kzg_settings::G1_POINTS,
        c_kzg::ethereum_kzg_settings::G2_POINTS,
    )
    .map_err(|e| KzgError::Kzg(format!("trusted setup: {e:?}")))?;
    let ckzg_blob = CKzgBlob::from_bytes(&blob.0.0)
        .map_err(|e| KzgError::Kzg(format!("blob bytes: {e:?}")))?;
    let proof = settings
        .compute_blob_kzg_proof(&ckzg_blob, commitment)
        .map_err(|e| KzgError::Kzg(format!("proof: {e:?}")))?;
    Ok(proof.to_bytes())
}
```

```solidity
    error TooManyBlobs(uint256 max, uint256 got);
    error ZeroOperator();
    error WrongL2ChainId(uint64 expected, uint64 got);

    /// Per-block state-root commitment recorded inside a single batch post.
    struct BlockCommitment {
        uint64 blockNumber;
        uint64 endTxIdx;
        uint64 l2Timestamp;
        bytes32 stateRoot;
    }

    /// EIP-4844 cap.
    uint256 public constant MAX_BLOBS = 6;

    uint64 public l2ChainId;
    address public operator;
    uint64 public lastBatchIndex;
    bytes32 public lastStateRoot;
    uint64 public lastBlockNumber;
    uint64 public lastEndTxIdx;

    event BatchPosted(
        uint64 indexed batchIndex,
        uint64 indexed l2ChainId,
        bytes32[] blobVersionedHashes,
        uint64 firstBlockNumber,
        uint64 lastBlockNumber,
        uint64 endTxIdx,
        bytes32 newStateRoot
    );
    event OperatorUpdated(address indexed oldOperator, address indexed newOperator);

    /// @custom:oz-upgrades-unsafe-allow constructor
    constructor() {
        _disableInitializers();
    }

    /// initialize(uint64 l2ChainId, address operator) — keyed for factory ABI.
    function initialize(uint64 _l2ChainId, address _operator) external initializer {
        if (_operator == address(0)) revert ZeroOperator();
        l2ChainId = _l2ChainId;
        operator = _operator;
    }

    function setOperator(address newOperator) external {
        if (msg.sender != operator) revert NotOperator();
        if (newOperator == address(0)) revert ZeroOperator();
        address old = operator;
        operator = newOperator;
        emit OperatorUpdated(old, newOperator);
    }

    /// Post one batch of L2 blocks. `prevBatchIndex` is the index this caller observed
    /// before sending (CAS); the call reverts if it doesn't match `lastBatchIndex` —
    /// the contract's replay protection.
    ///
    /// `blobVersionedHashes` must be present in this transaction's blob list. The EVM
    /// `BLOBHASH` opcode is the canonical check; we verify each entry matches the
    /// corresponding `tx.blobVersionedHashes[i]` (Solidity 0.8.26's `blobhash(i)` per
    /// EIP-7516).
    function postBatch(
        uint64 _l2ChainId,
        uint64 prevBatchIndex,
        bytes32[] calldata blobVersionedHashes,
        BlockCommitment[] calldata commitments
    ) external {
        if (msg.sender != operator) revert NotOperator();
        if (_l2ChainId != l2ChainId) revert WrongL2ChainId(l2ChainId, _l2ChainId);
        if (prevBatchIndex != lastBatchIndex) revert BadPrevIndex(lastBatchIndex, prevBatchIndex);
        if (blobVersionedHashes.length == 0) revert EmptyBlobHashes();
        if (blobVersionedHashes.length > MAX_BLOBS) revert TooManyBlobs(MAX_BLOBS, blobVersionedHashes.length);

        // Verify each blob hash matches a tx-level blob hash, in order.
        for (uint256 i = 0; i < blobVersionedHashes.length; i++) {
            bytes32 actual = blobhash(i);
            require(actual == blobVersionedHashes[i], "blob hash mismatch");
        }

        uint64 firstBlock = commitments[0].blockNumber;
        BlockCommitment calldata last = commitments[commitments.length - 1];
        // Block numbers must be strictly monotonic across posts.
        require(firstBlock == lastBlockNumber + 1 || lastBlockNumber == 0, "non-monotonic block");
        for (uint256 i = 1; i < commitments.length; i++) {
            require(commitments[i].blockNumber == commitments[i - 1].blockNumber + 1, "non-monotonic inner");
        }

        lastBatchIndex += 1;
        lastStateRoot = last.stateRoot;
        lastBlockNumber = last.blockNumber;
        lastEndTxIdx = last.endTxIdx;

        emit BatchPosted(
            lastBatchIndex,
            l2ChainId,
            blobVersionedHashes,
            firstBlock,
            last.blockNumber,
            last.endTxIdx,
            last.stateRoot
        );
    }
}
```

```rust
//! Resolve an operator EOA from a KeySource (env var / hex literal / keystore).

use alloy_primitives::Address;
use alloy_signer_local::PrivateKeySigner;
use std::path::Path;

use crate::config::KeySource;

#[derive(Debug, thiserror::Error)]
pub enum KeyError {
    #[error("env var {0} not set")]
    EnvMissing(String),
    #[error("invalid hex key: {0}")]
    BadHex(String),
    #[error("keystore read failed: {0}")]
    Keystore(String),
}

pub fn load_signer(src: &KeySource) -> Result<PrivateKeySigner, KeyError> {
    match src {
        KeySource::Hex(hex) => parse_hex(hex),
        KeySource::Env(name) => {
            let hex = std::env::var(name).map_err(|_| KeyError::EnvMissing(name.clone()))?;
            parse_hex(&hex)
        }
        KeySource::Keystore(path) => load_keystore(path),
    }
}

fn parse_hex(s: &str) -> Result<PrivateKeySigner, KeyError> {
    let hex = s.trim().trim_start_matches("0x");
    let bytes = hex::decode(hex).map_err(|e| KeyError::BadHex(e.to_string()))?;
    if bytes.len() != 32 {
        return Err(KeyError::BadHex(format!("len={}, want 32", bytes.len())));
    }
    let mut arr = [0u8; 32];
    arr.copy_from_slice(&bytes);
    PrivateKeySigner::from_bytes(&arr.into()).map_err(|e| KeyError::BadHex(e.to_string()))
}

fn load_keystore(path: &Path) -> Result<PrivateKeySigner, KeyError> {
    let pass = std::env::var("BATCHER_KEYSTORE_PASS")
        .map_err(|_| KeyError::EnvMissing("BATCHER_KEYSTORE_PASS".into()))?;
    PrivateKeySigner::decrypt_keystore(path, &pass).map_err(|e| KeyError::Keystore(e.to_string()))
}

pub fn signer_address(signer: &PrivateKeySigner) -> Address {
    signer.address()
}
```

```rust
//! Reconstruct an L2 batch from 4844 blobs (the inverse of `framing` + `blobs`).
//! No network calls — the caller supplies the blobs (read from a beacon node,
//! or in tests, taken straight from the post-side of the pipeline).

use crate::blobs::{PackedBlob, unpack_blobs};
use crate::framing::{DecodedFrame, FrameError, decode_frame};

#[derive(Debug, thiserror::Error)]
pub enum ReconstructError {
    #[error("zstd decompress failed: {0}")]
    Decompress(String),
    #[error("frame decode failed: {0}")]
    Frame(#[from] FrameError),
}

pub fn reconstruct_from_blobs(blobs: &[PackedBlob]) -> Result<DecodedFrame, ReconstructError> {
    let raw = unpack_blobs(blobs);
    // zstd streams are self-delimiting; the trailing zero-padding from
    // unpack_blobs is ignored by `decode_all`.
    let frame = zstd::stream::decode_all(&raw[..])
        .map_err(|e| ReconstructError::Decompress(e.to_string()))?;
    decode_frame(&frame).map_err(ReconstructError::Frame)
}
```

```rust
//! Build and send the EIP-4844 settlement transaction.
//!
//! Gas strategy (pinned for v0):
//!   * `max_fee_per_blob_gas`  = 2 × current `eth_blobBaseFee`, floored at 1 wei.
//!   * `max_fee_per_gas`       = `eth_baseFee` × 2 + `priority`, where `priority`
//!                               is `eth_maxPriorityFeePerGas()` (alloy fills this).
//!   * `gas_limit`             = `eth_estimateGas` × 12/10 (20% buffer).
//!
//! Replacement: not in scope for v0 — if a posting tx stalls, the standby
//! observes lease expiry and re-posts from the current `lastBatchIndex`.

use alloy_consensus::{SidecarBuilder, SidecarCoder, SimpleCoder, TxEip4844Variant};
use alloy_eips::eip4844::BlobTransactionSidecar;
use alloy_network::{Ethereum, EthereumWallet, TransactionBuilder, TransactionBuilder4844};
use alloy_primitives::{Address, B256, Bytes, TxHash, U256};
use alloy_provider::Provider;
use alloy_rpc_types_eth::{BlockNumberOrTag, TransactionRequest};
use alloy_signer_local::PrivateKeySigner;
use alloy_sol_types::{SolCall, sol};

use crate::blobs::PackedBlob;
use crate::framing::FramedBlock;

sol! {
    #[sol(rpc)]
    contract KardamomL2Settlement {
        struct BlockCommitment {
            uint64 blockNumber;
            uint64 endTxIdx;
            uint64 l2Timestamp;
            bytes32 stateRoot;
        }
        function postBatch(
            uint64 l2ChainId,
            uint64 prevBatchIndex,
            bytes32[] calldata blobVersionedHashes,
            BlockCommitment[] calldata commitments
        ) external;
        function lastBatchIndex() external view returns (uint64);
        function lastStateRoot() external view returns (bytes32);
        function lastBlockNumber() external view returns (uint64);
    }
}

#[derive(Debug, thiserror::Error)]
pub enum PostError {
    #[error("provider error: {0}")]
    Provider(String),
    #[error("kzg error: {0}")]
    Kzg(String),
    #[error("transaction reverted")]
    Reverted,
}

pub struct PostInputs<'a> {
    pub l2_chain_id: u64,
    pub prev_batch_index: u64,
    pub blocks: &'a [FramedBlock],
    pub blobs: &'a [PackedBlob],
}

pub async fn post_batch<P: Provider<Ethereum>>(
    provider: &P,
    wallet: &EthereumWallet,
    settlement: Address,
    inputs: PostInputs<'_>,
) -> Result<TxHash, PostError> {
    // (a) Build sidecar — blobs + commitments + proofs.
    let sidecar = build_sidecar(inputs.blobs)?;

    // (b) Encode calldata.
    let commitments: Vec<KardamomL2Settlement::BlockCommitment> = inputs
        .blocks
        .iter()
        .map(|b| KardamomL2Settlement::BlockCommitment {
            blockNumber: b.block_number,
            endTxIdx: b.end_tx_idx,
            l2Timestamp: b.l2_timestamp,
            stateRoot: b.state_root,
        })
        .collect();
    let blob_hashes: Vec<B256> = sidecar
        .versioned_hashes()
        .map(|h| h)
        .collect();
    let call = KardamomL2Settlement::postBatchCall {
        l2ChainId: inputs.l2_chain_id,
        prevBatchIndex: inputs.prev_batch_index,
        blobVersionedHashes: blob_hashes.clone(),
        commitments,
    };

    // (c) Build the tx.
    let blob_base_fee = provider
        .get_blob_base_fee()
        .await
        .map_err(|e| PostError::Provider(e.to_string()))?;
    let max_blob_fee = (blob_base_fee.saturating_mul(2)).max(1);

    let tx = TransactionRequest::default()
        .with_to(settlement)
        .with_input(Bytes::from(call.abi_encode()))
        .with_blob_sidecar(sidecar)
        .with_max_fee_per_blob_gas(max_blob_fee);

    let pending = provider
        .send_transaction(tx)
        .await
        .map_err(|e| PostError::Provider(e.to_string()))?;
    let receipt = pending
        .get_receipt()
        .await
        .map_err(|e| PostError::Provider(e.to_string()))?;
    if !receipt.status() {
        return Err(PostError::Reverted);
    }
    Ok(receipt.transaction_hash)
}

fn build_sidecar(blobs: &[PackedBlob]) -> Result<BlobTransactionSidecar, PostError> {
    // Build commitments + proofs for the given blobs.
    use alloy_eips::eip4844::Blob;
    use c_kzg::{Blob as CKzgBlob, KzgSettings};

    let settings = KzgSettings::load_trusted_setup_file_from_bytes(
        c_kzg::ethereum_kzg_settings::G1_POINTS,
        c_kzg::ethereum_kzg_settings::G2_POINTS,
    )
    .map_err(|e| PostError::Kzg(format!("setup: {e:?}")))?;

    let mut blob_vec: Vec<Blob> = Vec::with_capacity(blobs.len());
    let mut commitments = Vec::with_capacity(blobs.len());
    let mut proofs = Vec::with_capacity(blobs.len());

    for b in blobs {
        let ck = CKzgBlob::from_bytes(&b.0.0).map_err(|e| PostError::Kzg(format!("{e:?}")))?;
        let c = settings.blob_to_kzg_commitment(&ck).map_err(|e| PostError::Kzg(format!("{e:?}")))?;
        let p = settings.compute_blob_kzg_proof(&ck, &c.to_bytes()).map_err(|e| PostError::Kzg(format!("{e:?}")))?;
        blob_vec.push(Blob::from(b.0.0));
        commitments.push(alloy_eips::eip4844::Bytes48::from(c.to_bytes().into_inner()));
        proofs.push(alloy_eips::eip4844::Bytes48::from(p.to_bytes().into_inner()));
    }

    Ok(BlobTransactionSidecar::new(blob_vec, commitments, proofs))
}

/// Fetch the contract's `lastBatchIndex` — what `prevBatchIndex` must be to post next.
pub async fn read_last_batch_index<P: Provider<Ethereum>>(
    provider: &P,
    settlement: Address,
) -> Result<u64, PostError> {
    let c = KardamomL2Settlement::new(settlement, provider);
    let idx = c
        .lastBatchIndex()
        .call()
        .await
        .map_err(|e| PostError::Provider(e.to_string()))?;
    Ok(idx)
}
```

```rust
//! Singleton + hot-standby driver. Uses `kardamom-leases::compute_lease` once
//! per tick to decide whether this host should be posting batches.

use std::sync::Arc;
use std::time::{Duration, Instant};
use tokio::sync::Notify;
use tokio::time::interval;

use kardamom_leases::{HostId, LeaseConfig, LeaseState, PeerHeartbeat, compute_lease};

/// A `HeartbeatSource` provides the latest known heartbeats from peer batcher hosts.
/// Implementations: a small UDP gossip (default), or Aeron-backed in production.
#[async_trait::async_trait]
pub trait HeartbeatSource: Send + Sync {
    async fn snapshot(&self) -> Vec<PeerHeartbeat>;
}

pub struct StandbyLoop<H> {
    cfg: LeaseConfig,
    heartbeats: Arc<H>,
    shutdown: Arc<Notify>,
    /// Caller-supplied: how far this host has advanced its archive replay (channel-B position).
    caught_up_position: Arc<std::sync::atomic::AtomicU64>,
    /// Tick interval.
    tick: Duration,
}

impl<H: HeartbeatSource + 'static> StandbyLoop<H> {
    pub fn new(
        cfg: LeaseConfig,
        heartbeats: Arc<H>,
        caught_up_position: Arc<std::sync::atomic::AtomicU64>,
    ) -> Self {
        Self {
            cfg,
            heartbeats,
            shutdown: Arc::new(Notify::new()),
            caught_up_position,
            tick: Duration::from_millis(500),
        }
    }

    pub fn shutdown_handle(&self) -> Arc<Notify> {
        self.shutdown.clone()
    }

    /// Drive a callback whenever the lease transitions to `Held` / away from `Held`.
    pub async fn run<F, Fut>(self, mut on_state_change: F)
    where
        F: FnMut(LeaseState) -> Fut + Send + 'static,
        Fut: std::future::Future<Output = ()> + Send,
    {
        let mut ticker = interval(self.tick);
        let mut last = LeaseState::Inactive;
        loop {
            tokio::select! {
                _ = self.shutdown.notified() => break,
                _ = ticker.tick() => {
                    let peers = self.heartbeats.snapshot().await;
                    let pos = self.caught_up_position.load(std::sync::atomic::Ordering::Relaxed);
                    let now = Instant::now();
                    let state = compute_lease(&self.cfg, now, pos, &peers);
                    if state != last {
                        tracing::info!(?state, "batcher lease transition");
                        on_state_change(state.clone()).await;
                        last = state;
                    }
                }
            }
        }
    }
}
```

```rust
//! `kardamom-batcher` — the daemon. Subscribes to channel-C BlockBoundaries,
//! replays the corresponding channel-B range, packs into 4844 blobs, posts.
//!
//! Wire-up of the actual `BatchSource` (the S3 archive) lives outside this
//! crate. Until S3 ships, the binary takes a `--source mock=<path>` flag that
//! reads a sequence of (BlockBoundary, txs) JSON records from disk and replays
//! them — sufficient for the §6 conformance test driven by the bench harness.

use std::path::PathBuf;
use std::sync::Arc;

use alloy_network::EthereumWallet;
use alloy_provider::ProviderBuilder;
use anyhow::{Context, Result};
use clap::Parser;
use tracing_subscriber::EnvFilter;

use kardamom_batcher::blobs::pack_payload;
use kardamom_batcher::config::{BatcherConfig, KeySource};
use kardamom_batcher::framing::{FramedBlock, encode_frame};
use kardamom_batcher::keys::load_signer;
use kardamom_batcher::posting::{PostInputs, post_batch, read_last_batch_index};

#[derive(Parser, Debug)]
#[command(name = "kardamom-batcher")]
struct Cli {
    /// Path to a TOML config (see BatcherConfig).
    #[arg(long)]
    config: PathBuf,
    /// Source of BlockBoundary + tx-range events.
    /// `--source mock=<path>` reads a JSON file of pre-baked batches.
    /// `--source log=<aeron-config>` will be added once kardamom-log ships.
    #[arg(long, default_value = "mock=/dev/null")]
    source: String,
}

#[derive(serde::Deserialize)]
struct MockBatch {
    blocks: Vec<MockBlock>,
}
#[derive(serde::Deserialize)]
struct MockBlock {
    block_number: u64,
    l2_timestamp: u64,
    state_root_hex: String, // 0x-prefixed 32 bytes
    end_tx_idx: u64,
    /// 0x-prefixed EIP-2718-encoded txs.
    tx_envelopes_hex: Vec<String>,
}

#[tokio::main]
async fn main() -> Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::from_default_env())
        .init();
    let cli = Cli::parse();
    let cfg_raw = std::fs::read_to_string(&cli.config).with_context(|| format!("read {}", cli.config.display()))?;
    let cfg: BatcherConfig = toml::from_str(&cfg_raw).context("parse config")?;
    let signer = load_signer(&cfg.operator_key)?;
    let wallet = EthereumWallet::new(signer.clone());
    let provider = ProviderBuilder::new().wallet(wallet.clone()).connect_http(cfg.l1_rpc_url.parse()?);

    // Mock source for v0; replace with kardamom-log once S3 lands.
    let (kind, path) = cli.source.split_once('=').context("source must be kind=value")?;
    if kind != "mock" {
        anyhow::bail!("only --source mock=PATH is supported until S3 ships");
    }
    let batches: Vec<MockBatch> = serde_json::from_str(&std::fs::read_to_string(path)?)?;

    for batch in batches {
        let blocks: Vec<FramedBlock> = batch
            .blocks
            .into_iter()
            .map(|b| {
                let state_root = parse_b256(&b.state_root_hex)?;
                let txs = b
                    .tx_envelopes_hex
                    .iter()
                    .map(|h| parse_tx(h))
                    .collect::<Result<Vec<_>>>()?;
                Ok(FramedBlock {
                    block_number: b.block_number,
                    l2_timestamp: b.l2_timestamp,
                    state_root,
                    end_tx_idx: b.end_tx_idx,
                    txs,
                })
            })
            .collect::<Result<Vec<_>>>()?;

        let frame = encode_frame(cfg.l2_chain_id, &blocks)?;
        let compressed = zstd::stream::encode_all(&frame[..], cfg.zstd_level)?;
        let blobs = pack_payload(&compressed);
        anyhow::ensure!(
            blobs.len() <= cfg.max_blobs_per_tx as usize,
            "batch too large: {} blobs > max {}",
            blobs.len(),
            cfg.max_blobs_per_tx
        );

        let prev = read_last_batch_index(&provider, cfg.settlement_proxy).await?;
        let tx = post_batch(
            &provider,
            &wallet,
            cfg.settlement_proxy,
            PostInputs {
                l2_chain_id: cfg.l2_chain_id,
                prev_batch_index: prev,
                blocks: &blocks,
                blobs: &blobs,
            },
        )
        .await?;
        tracing::info!(?tx, blobs = blobs.len(), "posted batch");
    }
    Ok(())
}

fn parse_b256(s: &str) -> Result<alloy_primitives::B256> {
    let h = s.trim_start_matches("0x");
    let v = hex::decode(h)?;
    anyhow::ensure!(v.len() == 32, "state root must be 32 bytes");
    Ok(alloy_primitives::B256::from_slice(&v))
}

fn parse_tx(h: &str) -> Result<alloy_consensus::TxEnvelope> {
    use alloy_eips::eip2718::Decodable2718;
    let bytes = hex::decode(h.trim_start_matches("0x"))?;
    let mut s = bytes.as_slice();
    Ok(alloy_consensus::TxEnvelope::decode_2718(&mut s)?)
}
```

```rust
//! beacon-node-compatible endpoint and reconstruct the L2 batch as JSON.

use anyhow::{Context, Result};
use clap::Parser;

use kardamom_batcher::blobs::PackedBlob;
use kardamom_batcher::reconstruct::reconstruct_from_blobs;

#[derive(Parser, Debug)]
#[command(name = "kardamom-reconstruct")]
struct Cli {
    /// File containing blob bytes concatenated, each blob is 131072 bytes.
    /// (Production callers will fetch from a beacon node; for v0 we read from disk.)
    #[arg(long)]
    blobs: PathBuf,
}

fn main() -> Result<()> {
    let cli = Cli::parse();
    let raw = std::fs::read(&cli.blobs).with_context(|| format!("read {}", cli.blobs.display()))?;
    anyhow::ensure!(raw.len() % 131072 == 0, "blob file must be a multiple of 131072 bytes");
    let blobs: Vec<PackedBlob> = raw
        .chunks_exact(131072)
        .map(|c| {
            let mut b = Box::new(alloy_eips::eip4844::Blob::from([0u8; 131072]));
            b.0.copy_from_slice(c);
            PackedBlob(b)
        })
        .collect();
    let out = reconstruct_from_blobs(&blobs)?;
    println!(
        "{{\"l2_chain_id\":{},\"num_blocks\":{},\"num_txs\":{}}}",
        out.l2_chain_id,
        out.blocks.len(),
        out.blocks.iter().map(|b| b.txs.len()).sum::<usize>()
    );
    Ok(())
}
```

```rust
    let reconstructed = reconstruct_from_blobs(&blobs).unwrap();
    assert_eq!(reconstructed.l2_chain_id, L2_CHAIN_ID);
    assert_eq!(reconstructed.blocks.len(), 2);
    for (orig, got) in blocks.iter().zip(reconstructed.blocks.iter()) {
        assert_eq!(orig.block_number, got.block_number);
        assert_eq!(orig.state_root, got.state_root);
        assert_eq!(orig.end_tx_idx, got.end_tx_idx);
        assert_eq!(orig.txs.len(), got.txs.len());
        for (a, b) in orig.txs.iter().zip(got.txs.iter()) {
            let mut x = Vec::new(); a.encode_2718(&mut x);
            let mut y = Vec::new(); b.encode_2718(&mut y);
            assert_eq!(x, y, "tx must reconstruct byte-for-byte");
        }
    }
}
```

```markdown
# kardamom-batcher

L1 batcher subsystem (spec S7). Posts sealed L2 blocks to the
`KardamomL2Settlement` contract on Ethereum L1 via EIP-4844 blob transactions.

## Pipeline

1. Subscribe to `BlockBoundary` markers on channel C.
2. For each posting cycle (default every 10 L1 blocks), replay the
   corresponding `TxEnvelope` range from the channel-B archive.
3. Encode into a `KAR1`-magic frame (see `src/framing.rs`).
4. zstd-compress (level 3).
5. Pack into 4844 blobs at 31 bytes per field element → 126976 bytes payload
   per blob, up to 6 blobs per L1 tx.
6. Compute KZG commitments + proofs (via `c-kzg`).
7. Send one EIP-4844 transaction to `KardamomL2Settlement.postBatch(...)`.

## Inverse

The `reconstruct` module is the inverse: given the blobs (fetched via a
beacon-node sidecar API, or in tests held locally), it returns the original
`Vec<FramedBlock>` byte-for-byte. The §6 L1 round-trip conformance test
(`tests/conformance_l1_roundtrip.rs`) is the canonical end-to-end check.

## Binaries

* `kardamom-batcher` — the daemon. Reads `BatcherConfig` from TOML. For v0
  the source of batches is the `--source mock=<path>` flag (a JSON file).
  Once S3 ships, swap in `--source log=<aeron-config>`.
* `kardamom-reconstruct` — debug tool. Takes a file of concatenated 4844
  blob bytes and prints the decoded batch summary as JSON.

## Singleton + hot standby

Uses the `kardamom-leases` crate (lowest-host-id wins, heartbeat-driven).
Same mechanism the sealer (S5) uses.

## Settlement contract

Deployed via the existing `crates/deployer` (UUPS proxy through
`KardamomFactoryV1`). Register a new `ContractId::KardamomL2Settlement` op
and `applyDeployments` puts it on chain.

## Testing

* `cargo test -p kardamom-batcher` — unit + integration.
* `forge test --match-contract KardamomL2SettlementTest` — Solidity-side tests.
```
